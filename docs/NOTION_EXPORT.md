# Экспорт в Notion (API)

1. [Создайте интеграцию](https://www.notion.so/my-integrations) в Notion, скопируйте **Internal Integration Secret** (`secret_…`).
2. Создайте или выберите **родительскую страницу** в Notion. В меню **Share** добавьте интеграцию с правом редактирования.
3. В Sensify: **Настройки → Аккаунт** — вставьте секрет и ссылку на страницу (или UUID из URL).
4. После извлечения: **Экспорт → Отправить в Notion** (премиум). Создаётся дочерняя страница с блоками (резюме, идеи, карточки, заметки, ссылки, код).

**JSON-файл** по-прежнему доступен форматом «Notion» в списке экспорта — для ручного импорта или своих скриптов.

Токен хранится в `localStorage` (zustand persist) и передаётся на сервер **только** при нажатии кнопки; в логах сервера токен не пишется.
