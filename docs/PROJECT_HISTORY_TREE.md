# Древо эволюции Sensify (идея → реализация → внедрение)

Живая схема: как продукт вырос от концепции до текущего функционала. **Линейная детализация по версиям** — страница [`/changelog`](../src/app/changelog/page.tsx) в приложении и массив `changelog` в том же файле.

## Как вести документ дальше

1. Крупная ветка → короткий узел в дереве выше.  
2. Детали релиза → запись в `changelog` (`src/app/changelog/page.tsx`).  
3. Идеи без срока → `docs/PLANNED_FEATURES.md` и ТЗ.
