# Демо-файлы

`demo.pdf` — демо для кнопки «Показать работу» на вкладке PDF: к [W3C dummy.pdf](https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf) добавлен выделяемый текст (≥30 символов для парсера).

Пересобрать: `npm run demo-pdf` (нужен интернет, чтобы скачать базовый dummy.pdf).
